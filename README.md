# Relational Abilities Experiments

This repository contains synthetic relational benchmarks for testing whether tabular foundation models, knowledge-graph embedding baselines, and local/cloud LLMs can infer simple binary-relation properties from tabular examples.

The current experiments focus on:

- symmetry: `R(a,b) = R(b,a)`;
- non-transitive symmetry: symmetric relations that are not generated by hidden equivalence classes;
- antisymmetry: if `R(a,b)=1`, then `R(b,a)=0`;
- sparse `supervised_by`: a more realistic directed antisymmetric relation;
- LLM prompt-based ICL baselines through Ollama.

No dataset or result folder has been removed. Existing root-level dataset and result folders are kept in place so previous commands, reports, and paths remain valid.

## Core Data Contract

All model-facing relation datasets use the same minimal schema:

```text
entity_1,entity_2,label,split
```

The hidden information used to generate labels is saved only in audit files such as `entities.csv`, `pair_assignments.csv`, `positive_edges.csv`, or `positive_supervisions.csv`. It is not included in the model-facing atom table.

## Typical Commands

Generate the large random/sequential symmetry demo-fraction datasets:

```bash
python3 generate_minimal_symmetry_dataset.py --output-dir symmetry_demo_fraction_datasets/random_demo_0.0 --seed 20260514 --num-groups 100 --group-size 10 --negative-ratio 1.0 --split-mode symmetry_demonstration --demo-fraction 0.0 --validation-fraction 0.2
python3 generate_minimal_symmetry_dataset.py --output-dir symmetry_demo_fraction_datasets/sequential_demo_0.0 --seed 20260514 --num-groups 100 --group-size 10 --negative-ratio 1.0 --split-mode symmetry_demonstration --demo-fraction 0.0 --validation-fraction 0.2 --sequential-entity-ids
```

Run TabPFN on one dataset:

```bash
python3 run_minimal_symmetry_tfm_experiment.py \
  --data-path symmetry_demo_fraction_datasets/random_demo_0.0/symmetry_friendship_atoms.csv \
  --output-dir results_random_demo_0_0 \
  --models tabpfn \
  --device cuda \
  --tabpfn-model-path checkpoints/tabpfn/tabpfn-v3-classifier-20260506.ckpt
```

Run KGE baselines:

```bash
python3 run_kge_relation_baselines.py \
  --data-path minimal_antisymmetry_dataset/antisymmetry_coauthor_atoms.csv \
  --output-dir results_antisymmetry_kge \
  --models complex,transr,transe,distmult \
  --device cuda
```

Run Ollama LLM prompt sweep:

```bash
MODEL=qwen3:8b bash llm_exp/run_prompt_sweep.sh
```

For LLM/Ollama runs, additional files may include:


The most important files for comparison are `metrics.csv` files. Use `tools/repo_inventory.py` to list current datasets and result folders:

```bash
python3 tools/repo_inventory.py
```

## Interpretation Warning

Sequential entity IDs can leak hidden group structure through numeric blocks. Random-ID datasets are the cleaner tests of symbolic symmetry. Sequential-ID datasets are still useful as leakage/shortcut probes because they reveal whether a model exploits numeric regularities rather than a relational rule.
